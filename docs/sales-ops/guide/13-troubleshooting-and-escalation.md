# Troubleshooting and escalation

## Start with the basics

1. Check whether the device is online.
2. Refresh only after noting any unsynchronised local change.
3. Confirm you are signed in with the expected account.
4. Check whether the lead is claimed by another agent.
5. Read the exact error rather than replacing it with a guess.

If an offline edit is pending, restore connectivity and allow synchronisation to complete. Do not claim the same lead from two devices. Escalate with the page, action, approximate time and safe error text. Never include passwords, tokens or customer secrets.
