# GitHub fundamentals

GitHub stores the reviewed project files. A **repository** is the project, a **branch** is a line of work, a **commit** is a saved change, and a **pull request** is a request for review before merging.

Most team members only need to read files and review changes. Never paste passwords, access tokens, database URLs or customer information into a repository. The published Guide and Playbook appear in Lead Forge only after their approved changes are merged and deployed.
