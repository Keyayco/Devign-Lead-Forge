# Android and Termux

**Optional technical section:** most team members do not need Termux.

If you use it, work carefully:

- Confirm the current directory before opening or copying a file.
- Inspect a file before replacing it.
- Use a dry run when a tool provides one.
- Keep credentials out of shell history and files.
- Do not assume a particular Android storage path is the Devign source of truth.
- Do not run production migrations or deployment commands from a phone without explicit approval.

This phase does not provide an import script.
