# The lead workflow

## Find a lead

Use the search field and filters for Type, claim status and lead status. On mobile, use the lead card and open the brief for more context.

## Create a lead

Add the name first. Contact, email, type, address, demo link and notes are optional, but useful context makes the lead easier for the team to work.

## Edit a lead

Edit information when you learn something new. Keep notes factual and preserve useful existing context. Online edits use the protected server procedure. Offline-safe edits are stored locally and synchronised when connectivity returns.

## Claim a lead

Claim only when you are taking responsibility for the next action. The server confirms ownership atomically. If another agent has already claimed it, the queue refreshes and you must not treat the lead as yours.

Claiming is intentionally unavailable offline.
